# 老人购物｜上线适配说明

> 文档版本：V1.0

## 1. 上线结论

当前代码已具备测试环境部署条件，并已接入邀请码登录、用户身份隔离和 JSON/SQLite 快照备份适配；正式生产发布仍需完成云账号、TOS 桶、域名和真实用户策略配置。

已具备：

- 前后端源码已提交到 `phase-7-frontend-design` 分支。
- 前端可生成 Next.js standalone 产物。
- 前端支持生产构建时注入 API 地址，并可通过 Next.js 同源代理访问后端。
- 后端支持通过 `CORS_ORIGINS` 配置正式前端域名。
- 后端生产环境默认将未显式配置的数据目录落到 `/tmp/data`，并通过请求头返回 `x-request-id` 追踪号。
- 前后端各自包含 `.vefaasignore`，排除密钥、依赖缓存、测试缓存和本地运行数据。
- DeepSeek Key 仍只从后端环境变量读取。
- 生产环境通过 `AUTH_SECRET` 签发签名令牌；业务接口从令牌读取用户身份，不信任客户端传入的用户 ID。
- `backend/scripts/backup_data.py` 支持本地快照或火山 TOS 上传，`backend/scripts/restore_data.py` 支持恢复最近快照。
- 本地 typecheck、Lint、build 和后端测试已通过。

暂未具备：

- Git 远程仓库地址和云平台应用绑定。
- 前端、后端正式域名与 HTTPS。
- 短信/OIDC 等正式身份系统（当前是可替换的邀请码 MVP）。
- 生产数据库迁移和高并发并发控制；当前 JSON/SQLite 适合小规模测试。
- 真实支付、物流、通知和短信/OIDC 身份系统。
- 线上监控、告警、限流和正式审计存储。

## 2. 部署拓扑

```text
用户浏览器
    ↓ HTTPS
Next.js 前端
    ├─ 页面静态资源
    └─ /api/* 同源代理 → FastAPI 后端
                              ├─ JSON 商品/订单/售后数据
                              ├─ SQLite 家人协助数据
                              └─ DeepSeek API（仅后端出站）
```

前端构建时固定 `BACKEND_URL`；不要指望只修改云平台运行时变量就改变已经生成的 Next.js rewrite 目标。

## 3. 环境变量

### 前端构建环境

```text
NEXT_PUBLIC_API_BASE_URL=/api/v1
BACKEND_URL=https://你的后端域名
```

`NEXT_PUBLIC_` 变量会进入浏览器，只能放公开 API 路径，不能放密钥。

### 后端运行环境

```text
APP_ENV=production
ENV=prod
BACKEND_HOST=0.0.0.0
BACKEND_PORT=8000
CORS_ORIGINS=https://你的前端域名
DATA_DIR=/tmp/data
FAMILY_DB_PATH=/tmp/data/family.sqlite3
AUTH_SECRET=由部署平台密钥管理注入
AUTH_TOKEN_TTL_SECONDS=86400
INVITE_CODES=elder:老人邀请码,family:家人邀请码
BACKUP_PROVIDER=tos
BACKUP_PREFIX=elder-shopping
TOS_ENDPOINT=https://tos-cn-beijing.volces.com
TOS_BUCKET=你的私有桶名
TOS_REGION=cn-beijing
TOS_ACCESS_KEY=由部署平台密钥管理注入
TOS_SECRET_KEY=由部署平台密钥管理注入
DEEPSEEK_API_KEY=由部署平台密钥管理注入
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=实际可用模型名
DEEPSEEK_TIMEOUT_SECONDS=20
```

密钥不能写入 Git、Docker 镜像、前端 Bundle、日志或截图。

`/tmp` 只是 veFaaS 实例内可写的临时目录，不是最终的数据恢复方案。正式上线前需配置预留实例，并通过 TOS 定时运行快照命令；恢复前必须先设置 `RESTORE_CONFIRM=YES`，避免误覆盖当前数据。

### 3.1 本地验收备份/恢复

```bash
BACKUP_PROVIDER=local DATA_DIR=data \
  PYTHONPATH=backend .venv/bin/python backend/scripts/backup_data.py

RESTORE_CONFIRM=YES BACKUP_PROVIDER=local DATA_DIR=data \
  PYTHONPATH=backend .venv/bin/python backend/scripts/restore_data.py
```

### 3.2 TOS 备份

在火山引擎 TOS 创建私有桶，并把桶名、区域、Endpoint 和访问密钥配置到 veFaaS 的后端密钥管理，不要写进 `.env` 提交。配置完成后运行：

```bash
BACKUP_PROVIDER=tos DATA_DIR=/tmp/data \
  PYTHONPATH=backend python backend/scripts/backup_data.py
```

当前脚本上传商品、地址、购物车、订单、售后、助手审计和家人协助 SQLite 快照；正式环境应使用定时任务并定期做恢复演练。

## 4. 前端部署要求

1. 使用 Node.js 22 LTS 或平台已验证的兼容版本。
2. 执行 `npm ci`，使用锁文件安装依赖。
3. 以 `NEXT_PUBLIC_API_BASE_URL=/api/v1 BACKEND_URL=https://后端域名 npm run build` 构建。
4. 将 `.next/static` 复制到 `.next/standalone/.next/static`，将 `public` 复制到 `.next/standalone/public`。
5. 使用 `PORT=3000 node .next/standalone/server.js` 启动，或在 standalone 目录使用 `node server.js`。
6. 平台入口必须使用 HTTPS；语音能力在非 localhost 环境没有 HTTPS 时会受浏览器限制。

## 5. 后端部署要求

1. Python 3.11 环境执行 `pip install -r backend/requirements.txt`。
2. 使用 `PYTHONPATH=backend python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --proxy-headers` 启动；也可在 `backend/` 目录使用 `./run.sh`。
3. `DATA_DIR` 和 `FAMILY_DB_PATH` 必须指向可持久化目录；无持久盘时重启可能丢失演示数据。
4. 后端只允许正式前端域名进入 `CORS_ORIGINS`，不在生产使用 `*`。
5. 发布前访问 `/api/v1/health`、商品、订单和家人协助接口。
