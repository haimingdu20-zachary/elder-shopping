## 1. 上线结论

当前代码已具备测试环境部署条件，但尚不具备面向真实用户的正式生产条件。

已具备：

- 前后端源码已提交到 `phase-7-frontend-design` 分支。
- 前端可生成 Next.js standalone 产物。
- 前端支持生产构建时注入 API 地址，并可通过 Next.js 同源代理访问后端。
- 后端支持通过 `CORS_ORIGINS` 配置正式前端域名。
- DeepSeek Key 仍只从后端环境变量读取。
- 本地 typecheck、Lint、build 和后端测试已通过。

暂未具备：

- Git 远程仓库地址和云平台应用绑定。
- 前端、后端正式域名与 HTTPS。
- 生产数据库、备份、迁移和多用户隔离。
- 真实登录、权限体系、支付、物流和通知。
- 线上监控、告警、限流和正式审计存储。

## 2. 部署拓扑

```text
用户浏览器
    ↓ HTTPS
Next.js 前端
    ├─ 页面静态资源
    └─ /api/* 同源代理 → FastAPI 后端
                              ├─ JSON 商品/订单/售后数据
                              ├─ SQLite 家人协助数据
                              └─ DeepSeek API（仅后端出站）
```

前端构建时固定 `BACKEND_URL`；不要指望只修改云平台运行时变量就改变已经生成的 Next.js rewrite 目标。

## 3. 环境变量

### 前端构建环境

```text
NEXT_PUBLIC_API_BASE_URL=/api/v1
BACKEND_URL=https://你的后端域名
```

`NEXT_PUBLIC_` 变量会进入浏览器，只能放公开 API 路径，不能放密钥。

### 后端运行环境

```text
APP_ENV=production
BACKEND_HOST=0.0.0.0
BACKEND_PORT=8000
CORS_ORIGINS=https://你的前端域名
DATA_DIR=/持久化数据目录
FAMILY_DB_PATH=/持久化数据目录/family.sqlite3
DEEPSEEK_API_KEY=由部署平台密钥管理注入
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=实际可用模型名
DEEPSEEK_TIMEOUT_SECONDS=20
```

密钥不能写入 Git、Docker 镜像、前端 Bundle、日志或截图。

## 4. 前端部署要求

1. 使用 Node.js 22 LTS 或平台已验证的兼容版本。
2. 执行 `npm ci`，使用锁文件安装依赖。
3. 以 `NEXT_PUBLIC_API_BASE_URL=/api/v1 BACKEND_URL=https://后端域名 npm run build` 构建。
4. 将 `.next/static` 复制到 `.next/standalone/.next/static`，将 `public` 复制到 `.next/standalone/public`。
5. 使用 `PORT=3000 node .next/standalone/server.js` 启动，或在 standalone 目录使用 `node server.js`。
6. 平台入口必须使用 HTTPS；语音能力在非 localhost 环境没有 HTTPS 时会受浏览器限制。

## 5. 后端部署要求

1. Python 3.11 环境执行 `pip install -r backend/requirements.txt`。
2. 使用 `PYTHONPATH=backend uvicorn app.main:app --host 0.0.0.0 --port 8000 --proxy-headers` 启动。
3. `DATA_DIR` 和 `FAMILY_DB_PATH` 必须指向可持久化目录；无持久盘时重启可能丢失演示数据。
4. 后端只允许正式前端域名进入 `CORS_ORIGINS`，不在生产使用 `*`。
5. 发布前访问 `/api/v1/health`、商品、订单和家人协助接口。

- CLI 版本：`0.3.1`，满足当前操作要求。
- 当前目录没有 `.vefaas/config.json`，尚未绑定 Application。
- 当前未检测到登录凭据。
- `vefaas inspect` 会把本项目误判为单一 Node 应用；本项目必须按前端和后端两个应用分别部署，不能直接使用该默认检测结果。
- 首次部署前需要确定云平台、区域、网关、前后端应用名和持久化存储方案。
