## 1. 部署策略

采用前后端分离部署：

- 前端：Next.js standalone，独立访问域名。
- 后端：FastAPI，独立 API 域名或内部服务地址。
- 浏览器：请求前端同源 `/api/v1`。
- Next.js：通过构建时 `BACKEND_URL` rewrite 到后端 API。
- DeepSeek：仅从后端调用，前端不接触 Key。

当前后端已接入邀请码登录和令牌身份隔离；用户身份由后端令牌决定。家人协助仍以演示家人关系为 MVP，正式运营前应接入短信/OIDC 和可管理的关系绑定。

## 2. 本地生产模拟

### 2.1 构建前端

```bash
cd frontend
npm ci
NEXT_PUBLIC_API_BASE_URL=/api/v1 BACKEND_URL=http://127.0.0.1:8001 npm run build
cp -R .next/static .next/standalone/.next/static
cp -R public .next/standalone/public
```

### 2.2 启动后端

```bash
cd ..
APP_ENV=production ENV=prod BACKEND_HOST=127.0.0.1 BACKEND_PORT=8001 \
CORS_ORIGINS=http://127.0.0.1:3002 \
DATA_DIR=/tmp/elder-shopping-data FAMILY_DB_PATH=/tmp/elder-shopping-data/family.sqlite3 \
PYTHONPATH=backend .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --proxy-headers
```

### 2.3 启动 standalone 前端

```bash
cd frontend
PORT=3001 node .next/standalone/server.js
```

生产环境必须配置 `NEXT_PUBLIC_AUTH_REQUIRED=true`，前端使用 `sessionStorage` 保存短期访问令牌，不使用 LocalStorage 保存业务数据；令牌过期后回到登录页。

验证：

```bash
curl -I http://127.0.0.1:3001/
curl http://127.0.0.1:3001/api/v1/health
curl 'http://127.0.0.1:3001/api/v1/products?q=牛奶'
```

## 3. 云平台发布步骤

1. 创建或选择 Git 远程仓库，将 `phase-7-frontend-design` 推送到远程。
2. 创建后端应用，配置 Python 运行时、启动命令、端口、持久化目录和后端环境变量。
3. 发布后端并记录 HTTPS API 域名，先完成健康检查。
4. 创建前端应用，配置 Node.js 运行时、构建命令和 standalone 启动命令。
5. 在前端构建环境设置 `NEXT_PUBLIC_API_BASE_URL=/api/v1` 和 `BACKEND_URL=后端 HTTPS 域名`。
6. 发布前端，检查页面、静态资源、同源 API、移动端布局和语音权限。
7. 创建 TOS 私有桶，配置 `BACKUP_PROVIDER=tos`、`TOS_ENDPOINT`、`TOS_BUCKET`、`TOS_REGION` 和密钥；不要把 TOS 密钥放入 GitHub。
8. 发布后运行一次 `backend/scripts/backup_data.py`，验证 TOS 对象存在，再在隔离目录演练 `restore_data.py`。
9. 记录前后端发布版本、环境变量版本、域名和回滚方式。

## 4. 回滚策略

- 前端回滚到上一个构建版本，不修改用户浏览器本地状态。
- 后端回滚前确认数据 schema 未发生不可逆变化。
- 不删除线上数据目录，不使用 `git reset --hard` 代替发布回滚。
- DeepSeek 模型或 Key 失效时，助手自动规则降级；商品、订单核心流程仍应可用。

## 5. 当前阻塞项

- 未提供 Git 远程仓库 URL，无法替你执行 `git push`。
- 未登录云平台，无法创建或发布线上 Application。
- 正式域名、HTTPS、TOS 桶和定时备份尚未在云账号中配置。
- 当前登录是邀请码 MVP；短信/OIDC、关系绑定、备份调度和正式错误监控仍需上线配置。

因此当前可以完成测试环境部署适配，但不能在没有这些外部信息的情况下宣称正式上线完成。
